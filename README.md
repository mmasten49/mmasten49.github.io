# mmasten49.github.io

Personal site for Matthew Masten, built for a Module 1 prompt-and-context-engineering assignment at Xavier University.

Live: https://mmasten49.github.io

## What's here

A single-page site (`index.html`) covering current work across the Cincinnati Reds, Alloy Growth Lab, and Xavier, plus AI tools shipped during that work and a set of live resources built for Alloy.

## Stack

Plain HTML and CSS, no JS framework. Google Fonts (Anton, Inter, IBM Plex Mono) loaded via CDN. Published straight through GitHub Pages from the `main` branch.
